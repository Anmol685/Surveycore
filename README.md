# SurveyCore

## Overview

SurveyCore is a modern web-based survey management platform designed to simplify the process of creating, managing, and analyzing surveys. The application provides an intuitive and responsive user interface that enables users to efficiently design surveys and manage survey-related workflows.

The project was developed as part of a Frontend Development assignment, with a focus on clean architecture, responsive design, component reusability, and user experience.

## Installation and Setup

### Clone the Repository

```bash
git clone https://github.com/Anmol685/Surveycore.git
```

### Navigate to the Project Directory

```bash
cd Surveycore
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
